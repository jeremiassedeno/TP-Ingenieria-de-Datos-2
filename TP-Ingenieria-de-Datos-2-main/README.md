# TP-Ingenieria-de-Datos-2
Proyecto realizado en Java para trabajar con distintos motores de bases de datos utilizando un enfoque de persistencia políglota.

Actualmente el proyecto implementa conexiones con:

MongoDB

Apache Cassandra

Neo4j

El objetivo es utilizar distintos modelos de bases de datos según las necesidades de almacenamiento y consulta de la aplicación.
